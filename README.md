# Meu App — Login e Dashboard com Expo

Aplicativo mobile simples feito com **Expo**, **React Native** e **Expo Router**.

## Funcionalidades

- Tela de Login (login, senha oculta e botão Acessar)
- Validação de campos obrigatórios
- Autenticação simulada
- Tela de Dashboard com mensagem de boas-vindas
- Botão Sair (volta para o Login)

## Como executar

```bash
npm install
npx expo start
```

Depois, abra no Expo Go (celular), emulador Android ou simulador iOS.

```
app/
├── _layout.tsx    # configuração da navegação
├── index.tsx      # tela de Login
└── dashboard.tsx  # tela de Dashboard
```
